# AWS Security Labs

Hands-on AWS labs focused on cloud security, documented step by step.

I am Cédric Bardoul, AWS Certified Cloud Practitioner (CLF-C02),
currently preparing the Solutions Architect Associate (SAA-C03).
This repository collects the labs I build in my own AWS account.
The goal is to show what I can actually do, not only what I have certified.

Each lab follows the same structure: the problem, the AWS services used,
the steps, the checks that prove it works, and the teardown.

## Labs

| # | Lab | Services | Status |
|---|---|---|---|
| 01 | IAM: users, groups, roles and least privilege | IAM | In progress |
| 02 | Encryption at rest | KMS, S3 | Planned |
| 03 | Auditing API activity | CloudTrail, S3 | Planned |
| 04 | Configuration compliance | AWS Config | Planned |
| 05 | Threat detection | GuardDuty | Planned |

## Environment

All labs run in a personal AWS account (eu-west-3, Paris) under Free Tier,
with a monthly budget alert. Every lab ends with a teardown checklist.
